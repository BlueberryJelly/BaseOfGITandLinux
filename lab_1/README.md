##  Подзадание 2
Найдите число слов, которые содержат ровно 2 буквы ‘a’ без учета их регистра.

```bash
tr -s '[:space:]' '\n' < dictionary_2026.txt | grep -ic '^[^a]*a[^a]*a[^a]*$'
```

## Подзадание 3
Найдите слова, которые содержат ровно 3 буквы ‘e’, отделенные друг от друга хотя бы одним
другим символом. Среди найденных слов выведите на экран количество слов длина которых строго
меньше 9 символов.

```bash
tr -s '[:space:]' '\n' < dictionary_2026.txt \
| grep -E '^[^e]*e[^e]+e[^e]+e[^e]*$' \
| awk 'length($0) < 9 { count++ } END { print count+0 }'
``` 

## Подзадание 4
Определите первые 3 упорядоченных набора из 3-х первых букв, которые наиболее часто
встречаются для слов, которые содержат смежные ‘e’. Пример слова со смежными ‘e’: слово «see».
Среди найденных наборов определите и выведите на экран в алфавитном порядке четыре набора
из первых трех букв, которые встречаются наиболее часто и в которых первая буква заглавная.

```bash
tr -s '[:space:]' '\n' < dictionary_2026.txt \
| grep 'ee' | grep -E '^[A-Z]{1}[^[:digit:]]{2}' | cut -c1-3 \
| sort | uniq -c | sort -rn \
| head -n 4 | sort -k2,2 | awk '{print $2}'
```
